# Endpoint catalog

Every endpoint whose wire shape has been derived from the client binary, newest work included.
One file per route; the description is the answer in one line, the file has the field tables,
offsets, RVAs and the client-side requirements.

**Grep this table for a path fragment**, then read the single file it names. Do not read the
whole directory.

Service names come from `../conventions/recnet-service-enum.md` and pick the subdomain.
A blank service means the note does not pin one (usually a DTO or payload rather than a route).
